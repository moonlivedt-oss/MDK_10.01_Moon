# 2.4 Векторы и строки

Вектор (`std::vector`) и строка (`std::string`) — базовые контейнеры стандартной библиотеки C++.

Общие свойства обоих контейнеров:

- элементы хранятся в непрерывном фрагменте памяти (друг за другом);
- есть доступ к элементу по индексу;
- добавление нового элемента в конец выполняется эффективно.

---

## Контейнер `std::vector`

`std::vector` — это **динамический массив**: он меняет свой размер по мере необходимости и быстро принимает новые элементы в конец. Вектор сам управляет выделенной памятью и гарантирует отсутствие утечек (подробнее об этом — в параграфах про управление памятью; пока достаточно знать, что это свойство есть).

Для работы с вектором подключается заголовочный файл `<vector>`.

### Тип элементов

Все элементы вектора имеют один и тот же тип, и этот тип должен быть известен на этапе компиляции. Он указывается в угловых скобках:

| Запись | Что означает |
|---|---|
| `std::vector<int>` | вектор целых чисел типа `int` |
| `std::vector<std::string>` | вектор строк |
| `std::vector<std::vector<int>>` | вектор векторов целых чисел (матрица) |

Само имя `std::vector` типом данных не является — это **шаблон**. Конкретный тип получается только после подстановки параметра (типа элемента). Шаблоны подробно разбираются в параграфе «Шаблоны».

### Создание вектора

Первый способ — [список инициализации](https://en.cppreference.com/w/cpp/utility/initializer_list), в котором элементы перечисляются через запятую:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    for (int elem : data) {
        std::cout << elem << " ";
    }
    std::cout << "\n";
}
```

Здесь для печати используется цикл `range-for`, который проходит по всем элементам контейнера.

Второй способ — указать число элементов и, при необходимости, образец элемента:

```cpp
#include <string>
#include <vector>

int main() {
    std::vector<std::string> v1;              // пустой вектор строк
    std::vector<std::string> v2(5);           // вектор из пяти пустых строк
    std::vector<std::string> v3(5, "hello");  // вектор из пяти строк "hello"
}
```

## Обращение к элементам

Вектор хранит элементы последовательно, поэтому положение элемента в памяти находится по индексу быстро. Индексация начинается с нуля:

```cpp
std::vector<int> data = {1, 2, 3, 4, 5};
int a = data[0];  // начальный элемент вектора
int b = data[4];  // последний элемент вектора (всего элементов пять)
data[2] = -3;     // заменяем элемент 3 на -3
```

Общее количество элементов возвращает функция `size`:

```cpp
std::cout << data.size() << "\n";
```

Отрицательные индексы, в отличие от некоторых других языков программирования, не допускаются.

### Квадратные скобки не проверяют индекс

При обращении через квадратные скобки корректность индекса **не проверяется**. Это проявление принципа «не платить за то, что не используется»: встроенные проверки замедляют программу, а предполагается, что код написан правильно и индекс `i` в выражении `data[i]` неотрицателен и удовлетворяет условию `i < data.size()`.

Обращение по некорректному индексу приводит к **неопределённому поведению**: программа попытается прочитать память, не принадлежащую вектору.

Если корректность индекса не гарантирована, используется функция `at`. Она проверяет индекс и бросает исключение:

```cpp
std::vector<int> data = {1, 2, 3, 4, 5};

std::cout << data[42] << "\n";     // неопределённое поведение: может произойти всё что угодно
std::cout << data.at(0) << "\n";   // напечатается 1
std::cout << data.at(42) << "\n";  // исключение std::out_of_range — его можно перехватить и обработать
```

Работа с исключениями разбирается в параграфе [«Обработка исключений»](https://education.yandex.ru/handbook/cpp/article/exceptions).

### Функции `front`, `back` и `empty`

Функции `front` и `back` возвращают первый и последний элемент без использования индексов:

```cpp
std::vector<int> data = {1, 2, 3, 4, 5};
std::cout << data.front() << "\n";  // то же, что data[0]
std::cout << data.back() << "\n";   // то же, что data[data.size() - 1]
```

Вызов любой из них на **пустом** векторе приводит к неопределённому поведению.

Для проверки на пустоту вместо сравнения `data.size() == 0` принято использовать функцию `empty`, возвращающую логическое значение:

```cpp
if (!data.empty()) {
    // вектор не пуст, с ним можно работать
}
```

## Итерация по индексам

### Тип `size_t`

В стандартной библиотеке индексы и размеры контейнеров имеют **беззнаковый** тип. Вместо `unsigned int` или `unsigned long int` для него используется традиционный псевдоним `size_t` (точнее — `std::vector<T>::size_type`). Фактически `size_t` совпадает с `uint32_t` или `uint64_t` в зависимости от битности платформы. Его использование дополнительно подчёркивает, что речь идёт об индексе или размере.

### Каноническая форма цикла

```cpp
for (size_t i = 0; i != data.size(); ++i) {
    std::cout << data[i] << " ";
}
```

В такой записи принято использовать сравнение `!=` и префиксный `++i`. Для целых чисел разницы с другими вариантами (`<` и постфиксный `i++`) нет, но она появится позже, в аналогичных циклах по итераторам других контейнеров. Поэтому имеет смысл сразу привыкнуть к этой форме.

### Ловушка беззнаковой арифметики

По правилам, унаследованным от языка C, результат арифметических действий над беззнаковым и знаковым типами приводится к беззнаковому типу. Значит, выражение `data.size() - 1` тоже беззнаковое. Если `data.size()` равен нулю, результат будет не минус единицей, а **самым большим беззнаковым целым** (для 64-битной платформы это 2⁶⁴ − 1).

Ошибочный код, проверяющий наличие в векторе идущих подряд дубликатов:

```cpp
// итерация по всем элементам, кроме последнего:
for (size_t i = 0; i < data.size() - 1; ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate value: " << data[i] << "\n";
    }
}
```

На пустом векторе эта программа работает некорректно: условие `i < data.size() - 1` на первой итерации окажется истинным, и произойдёт обращение к элементам пустого вектора.

Два корректных варианта:

```cpp
// вариант 1: перенести единицу в левую часть неравенства
for (size_t i = 0; i + 1 < data.size(); ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate value: " << data[i] << "\n";
    }
}
```

```cpp
// вариант 2: внешняя функция std::ssize из C++20 возвращает знаковый размер
for (std::int64_t i = 0; i < std::ssize(data) - 1; ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate value: " << data[i] << "\n";
    }
}
```

## Добавление и удаление элементов

Эффективно добавлять и удалять элементы вектор умеет **только с конца** — для этого есть функции `push_back` и `pop_back`.

Программа считывает числа с клавиатуры в вектор, а затем удаляет все нули в конце:

```cpp
#include <iostream>
#include <vector>

int main() {
    int x;
    std::vector<int> data;
    while (std::cin >> x) {  // читаем числа, пока не закончится ввод
        data.push_back(x);   // добавляем очередное число в вектор
    }

    while (!data.empty() && data.back() == 0) {
        // пока вектор не пуст и последний элемент равен нулю
        data.pop_back();  // удаляем этот нулевой элемент
    }
}
```

Добавление и удаление элементов в других частях вектора неэффективно: требуется сдвиг соседних элементов. Поэтому отдельных функций для работы с началом вектора не предусмотрено. Такие операции выполняются общими функциями `insert` и `erase` с использованием итераторов — соответствующие примеры разбираются позже.

Удалить сразу все элементы можно функцией `clear`.

## Резерв памяти

Вектор хранит элементы непрерывной последовательностью, и в конце этой последовательности резервируется дополнительное место для быстрого добавления новых элементов. Когда резерв заканчивается, при вставке очередного элемента происходит **реаллокация**: элементы копируются в новый, более просторный блок памяти.

Реаллокация — дорогая процедура, но если она происходит достаточно редко, её влияние незначительно. Можно доказать, что при выборе нового блока вдвое большего размера [амортизационная сложность](https://en.wikipedia.org/wiki/Amortized_analysis) добавления элемента будет константной.

Текущий резерв возвращает функция `capacity` (её не следует путать с `size`).

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2};
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(3);
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(4);
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(5);
    std::cout << data.size() << "\t" << data.capacity() << "\n";
}
```

Вывод программы:

```
2	2
3	4
4	4
5	8
```

Размер вектора растёт на единицу, а резерв удваивается после исчерпания. При добавлении четвёрки используется уже имеющаяся в резерве память, а при добавлении тройки и пятёрки происходит реаллокация.

> Коэффициент роста резерва зависит от реализации стандартной библиотеки. Чаще всего он равен двум, но конкретные числа стандартом не заданы и на другом компиляторе могут отличаться.

### Функция `reserve`

Если число элементов известно заранее, нужный объём памяти можно зарезервировать сразу — тогда при добавлении элементов реаллокаций не будет. Пусть на вход сначала подаётся число слов, а потом сами слова:

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> words;

    size_t words_count;
    std::cin >> words_count;

    // размер вектора остаётся нулевым, меняется только резерв:
    words.reserve(words_count);

    for (size_t i = 0; i != words_count; ++i) {
        std::string word;
        std::cin >> word;
        // все добавления будут дешёвыми, без реаллокаций:
        words.push_back(word);
    }
}
```

Если передать в `reserve` величину меньше текущего резерва, ничего не изменится — резерв останется прежним.

### Функция `resize`

`reserve` не следует путать с `resize`, которая меняет само **количество элементов**:

- аргумент меньше текущего размера — лишние элементы в конце удаляются;
- аргумент больше текущего размера — при необходимости происходит реаллокация, и в конец добавляются новые элементы со значением по умолчанию для данного типа.

```cpp
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    data.reserve(10);  // поменяли резерв, но размер вектора остался равным пяти

    data.resize(3);    // удалили последние элементы 4 и 5
    data.resize(6);    // получили вектор 1, 2, 3, 0, 0, 0
}
```

**Итог:** `reserve` меняет только резерв, `resize` — только размер (а резерв, если нужно, увеличивается автоматически).

## Многомерные векторы

Матрицу (таблицу) удобно хранить как вектор векторов. Пусть на вход программы сначала поступают число строк и число столбцов, а затем сами элементы построчно:

```cpp
#include <iostream>
#include <vector>

int main() {
    size_t m, n;
    std::cin >> m >> n;  // число строк и столбцов

    // создаём матрицу из m строк, каждая из которых — вектор из n нулей
    std::vector<std::vector<int>> matrix(m, std::vector<int>(n));

    for (size_t i = 0; i != m; ++i) {
        for (size_t j = 0; j != n; ++j) {
            std::cin >> matrix[i][j];
        }
    }

    // печатаем матрицу, выводя элементы через табуляцию
    for (size_t i = 0; i != m; ++i) {
        for (size_t j = 0; j != n; ++j) {
            std::cout << matrix[i][j] << "\t";
        }
        std::cout << "\n";
    }
}
```

Матрица здесь создаётся заранее заполненной нулями, а затем её элементы просто заменяются считанными значениями.

## Сортировка вектора

Для сортировки в заголовочном файле `<algorithm>` есть готовая функция `sort`. Гарантируется, что в худшем случае её сложность составляет O(n log n), где n — число элементов. Типичные реализации используют алгоритм [Introsort](https://en.wikipedia.org/wiki/Introsort).

```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};

    // сортировка диапазона вектора от начала до конца
    std::sort(data.begin(), data.end());

    // получим вектор 1, 1, 2, 3, 4, 5, 6, 9
}
```

В `sort` передаются **итераторы**, ограничивающие рассматриваемый диапазон. В примере это диапазон, совпадающий со всем вектором: соответствующие итераторы возвращают функции `begin` и `end` (их не следует путать с `front` и `back` — те возвращают сами элементы). Итераторы можно считать обобщёнными индексами; они есть и у контейнеров, не допускающих обычную индексацию. Подробный разбор итераторов — в отдельном параграфе.

Для сортировки по убыванию передаются обратные итераторы `rbegin` и `rend`, представляющие элементы в перевёрнутом порядке:

```cpp
std::sort(data.rbegin(), data.rend());  // 9, 6, 5, 4, 3, 2, 1, 1
```

В C++20 доступен более короткий способ — `std::ranges::sort`, которому передаётся сам вектор:

```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};

    std::ranges::sort(data);  // можно передать сам вектор, а не его диапазон
}
```

По умолчанию элементы сравниваются оператором `<`. Этот оператор определён и для самих векторов: они сравниваются [лексикографически](https://en.wikipedia.org/wiki/Lexicographic_order). Благодаря этому без дополнительных усилий сортируются, например, строки матрицы (то есть элементы вектора векторов).

## Строки

Контейнер `std::string` можно рассматривать как особый случай вектора символов `std::vector<char>` с [набором дополнительных функций](https://en.cppreference.com/w/cpp/string/basic_string). Все рассмотренные выше функции вектора (`size`, `empty`, `at`, `push_back`, `pop_back`, `resize` и другие) у строки тоже есть.

Для работы со строками подключается заголовочный файл `<string>`.

### Добавление, подстроки и поиск

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string";

    // приписывание символов и строк
    s += ' ';           // добавляем отдельный символ в конец, это аналог push_back
    s += "functions";   // добавляем строку в конец
    std::cout << s << "\n";  // Some string functions

    // выделение подстроки
    std::string sub1 = s.substr(5, 6);  // "string": 6 символов начиная с 5-й позиции
    std::string sub2 = s.substr(12);    // "functions": с 12-й позиции и до конца

    // поиск символа или подстроки
    size_t pos1 = s.find(' ');            // позиция первого пробела — 4
    size_t pos2 = s.find(' ', pos1 + 1);  // позиция следующего пробела — 11
    size_t pos3 = s.find("str");          // вернётся 5
    size_t pos4 = s.find("#");            // вернётся std::string::npos
}
```

Если подстрока не найдена, `find` возвращает специальное значение `std::string::npos`. Результат поиска обычно сравнивается именно с ним:

```cpp
if (s.find("str") != std::string::npos) {
    // подстрока найдена
}
```

### Вставка, замена и удаление подстрок

Эти операции задаются индексом начала и длиной подстроки:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string functions";

    // вставка подстроки
    s.insert(5, "std::");
    std::cout << s << "\n";  // Some std::string functions

    // замена указанного диапазона на новую подстроку
    s.replace(0, 4, "Special");
    std::cout << s << "\n";  // Special std::string functions

    // удаление подстроки
    s.erase(8, 5);  // Special string functions
}
```

Аналогичные действия для других контейнеров (например, для вектора) выполняются через итераторы — соответствующие примеры разбираются в одном из следующих параграфов.

### Проверка префикса и суффикса

В C++20 появились функции `starts_with` и `ends_with`:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string phrase;
    std::getline(std::cin, phrase);

    if (phrase.starts_with("hello")) {
        std::cout << "Greeting\n";
    }

    if (phrase.ends_with("bye")) {
        std::cout << "Farewell\n";
    }
}
```

Здесь для чтения строки целиком, вместе с пробелами, используется `std::getline`, а не `std::cin >>`.

## Сводка функций

### Общие для `std::vector` и `std::string`

| Функция | Назначение | Примечание |
|---|---|---|
| `size()` | количество элементов | тип результата — `size_t` |
| `empty()` | проверка на пустоту | предпочтительнее, чем `size() == 0` |
| `operator[]` | доступ по индексу | без проверки индекса |
| `at(i)` | доступ по индексу | бросает `std::out_of_range` |
| `front()`, `back()` | первый и последний элемент | на пустом контейнере — неопределённое поведение |
| `push_back(x)` | добавить элемент в конец | эффективно |
| `pop_back()` | удалить последний элемент | эффективно |
| `clear()` | удалить все элементы | |
| `resize(n)` | изменить количество элементов | |
| `reserve(n)` | зарезервировать память | размер не меняется |
| `capacity()` | текущий резерв | |
| `begin()`, `end()` | итераторы на начало и конец | |
| `rbegin()`, `rend()` | обратные итераторы | |

### Специфичные для `std::string`

| Функция | Назначение |
|---|---|
| `s += x` | приписать символ или строку в конец |
| `substr(pos, len)` | подстрока длины `len` с позиции `pos` |
| `substr(pos)` | подстрока с позиции `pos` до конца |
| `find(x)`, `find(x, pos)` | поиск символа или подстроки; при неудаче — `std::string::npos` |
| `insert(pos, str)` | вставить подстроку с позиции `pos` |
| `replace(pos, len, str)` | заменить диапазон на новую подстроку |
| `erase(pos, len)` | удалить подстроку |
| `starts_with(str)` | проверка префикса (C++20) |
| `ends_with(str)` | проверка суффикса (C++20) |
